# Snake Game — React + TypeScript + Vite

A small Snake game built with React, TypeScript and Vite. This repository contains the source for a minimal playable game and a tiny demo app.

## Features
- Fast dev server with HMR via Vite
- TypeScript for safer code
- Simple game logic in `src/game.ts`

## Prerequisites
- Node.js 18+ (or compatible LTS)
- npm or yarn

## Quick Start
Install dependencies and start the dev server:

```bash
npm install
npm run dev
```

Open the app at the URL shown in the terminal (usually `http://localhost:5173`).

## Build & Preview
Build for production and preview the built app locally:

```bash
npm run build
npm run preview
```

## Scripts
- `dev` — start Vite dev server
- `build` — build production bundle
- `preview` — preview production build

See `package.json` for the exact script definitions.

## Project Structure
- `src/` — React app and game logic
  - `App.tsx` — main app component
  - `game.ts` — core game logic
  - `main.tsx` — entry
- `public/` — static assets
